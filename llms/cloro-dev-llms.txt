# cloro

> cloro is an API for extracting structured data from AI answer engines and search results -- ChatGPT, Perplexity, Gemini, Copilot, Grok, Google AI Mode, AI Overview, and Google Search -- returned as markdown with sources and citations.

- [cloro | The API for Google Search and AI Answers](https://cloro.dev/): cloro is one API for search and AI answers: pull Google, ChatGPT, Gemini, Perplexity and Copilot results as clean markdown with sources and citations.
